# System Overview

---

## Overview

The **System** section provides administrators with access to node-level operating system configuration and information. It includes settings and tools used to manage system time, DNS, hostname resolution, logging, time synchronization, kernel management, and boot configuration.

These settings affect the selected node only and are used to maintain a stable, secure, and properly configured VM2Cloud environment.

The System section allows administrators to review the current configuration, make changes where supported, and troubleshoot operating system–related issues directly from the VM2Cloud web interface.

---

## When to Use

Use the **System** section to:

- Configure the system date and time.
- Configure DNS settings.
- Manage hostname resolution.
- Review system logs.
- Configure network time synchronization (NTP).
- View or manage installed kernels.
- Review boot mode information.
- Troubleshoot node operating system issues.

---

## Available Components

The System section contains the following configuration pages:

| Component | Purpose |
|-----------|---------|
| Time | Displays and configures the system date, time, and time zone. |
| DNS | Configures DNS servers and search domains used by the node. |
| Hosts | Manages local hostname resolution entries. |
| Syslog | Displays operating system log messages generated by the node. |
| Network Time (NTP) | Configures and monitors time synchronization services. |
| Boot Mode | Displays the node's boot mode and related information. |
| Kernel | Displays installed kernels and allows kernel management where supported. |

---

## Prerequisites

Before modifying system settings, ensure that:

- You are logged in to the VM2Cloud web interface.
- You have administrative privileges.
- The selected node is online.
- You understand the impact of the configuration change.

---

## Best Practices

- Verify configuration values before saving changes.
- Synchronize time across all cluster nodes.
- Use reliable DNS servers.
- Monitor system logs regularly.
- Keep the node updated with supported kernel versions.
- Perform configuration changes during maintenance windows whenever possible.
